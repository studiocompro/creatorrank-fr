CreatorRank FR — patch monétisation

Ce paquet n'écrase PAS les données JSON actualisées par GitHub Actions.

Contenu :
- ads.txt officiel AdSense
- support.html
- configuration des 3 emplacements publicitaires
- liaison de la CMP Google au bouton de confidentialité
- code AdSense global sur les pages
- page Publicité & financement mise à jour

Après upload GitHub :
1. Vérifier https://creatorrank-fr.pages.dev/ads.txt
2. Attendre l'approbation AdSense.
3. Créer 3 blocs d'annonces manuels et renseigner leurs IDs dans assets/ads-config.js.
4. Dans AdSense > Confidentialité et messages > Offerwall, cibler /support.html et activer « Annonce avec récompense ».
5. Pour le soutien direct, mettre ton lien PayPal/Ko-fi dans assets/support-config.js.
